# 1. Distribution chosen for the Kubernetes cluster

Date: 2026-10-29

## Status
Accepted

## Context
Is required from the user a distribution of their choices among the following :
> kubeadm
> RKE2
> k3s

## Decision
It has been chosen kubeadm

## Consequences
- Vanilla Kubernetes tools available
- ETCD by default
- Vendor neutral Kubernetes
